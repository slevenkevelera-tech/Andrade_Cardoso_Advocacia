# Andrade Cardoso Advocacia

Site profissional para o escritório de advocacia Andrade Cardoso.

## 📱 Sobre o Projeto

Este é um projeto moderno construído com React, TypeScript e Vite, oferecendo uma interface elegante e responsiva para apresentar os serviços jurídicos do escritório.

## 🛠️ Stack Tecnológico

- **Frontend**: React 19 + TypeScript
- **Build**: Vite
- **Styling**: Tailwind CSS
- **Backend**: Express
- **Banco de Dados**: Firebase
- **AI**: Google Generative AI
- **Animações**: Motion
- **Icons**: Lucide React

## 🚀 Quick Start

```bash
# Instale as dependências
npm install

# Configure seu arquivo .env.local
cp .env.example .env.local

# Inicie o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:3000`

- `npm run start` - Inicia em modo produção
- `npm run lint` - Verifica tipos TypeScript
- `npm run clean` - Limpa arquivos de build
